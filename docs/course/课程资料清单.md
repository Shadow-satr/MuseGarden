# MuseGarden 软件工程课程资料清单

本目录用于整理课程项目材料。项目由一人开发；以下内容按实际完成情况填写，待核实的内容不作为已完成成果。

## 项目概况

MuseGarden 是以文字记忆为输入，将音乐创作与花园互动结合的应用。当前项目记录的主要流程为：在花园空地输入记忆，生成音乐与花朵，随后查看记忆、播放音乐，以及修改和选择音乐版本。实际运行依赖本机 Ollama、ACE-Step 及其模型，运行条件见 [前端说明](../../frontend/README.md)。

项目代码包含 AI、音乐、花朵、应用服务、后端和前端模块。已有开发进度和已知限制见 [跨模块进度](../architecture/MuseGarden_progress.py) 和 [阶段里程碑](../architecture/MuseGarden_phase_milestone.md)。这些记录中的测试结果是历史记录，提交前需重新核验。

## 使用和已知限制

目前项目主要面向本机运行；完整 AI 音乐生成依赖本机服务和模型。项目记录指出历史记忆检索尚未接入当前创作流程，当前版本不包含完整多用户体系。对外展示和报告应以实际运行结果为准。
