# MuseGarden（音迹花园）运行与使用说明

> 适用版本：当前本地课程项目版本  
> 使用方式：Windows 本地运行

## 1. 项目简介

MuseGarden 是一个结合 AI 音乐生成与像素风花园的本地应用。用户可以输入一段文字记忆，系统会生成对应音乐和花朵，并将花朵种植到花园中。用户还可回顾记忆、播放音乐、查看音乐解读、修改音乐版本和删除花朵。

## 2. 运行环境

项目依赖以下本地环境：

| 项目 | 用途 | 要求 |
| --- | --- | --- |
| Windows | 运行平台 | 建议在 Windows 环境运行 |
| Python 虚拟环境 | 后端与业务逻辑 | 项目根目录应存在 `.venv` |
| Node.js 与 npm | 运行前端 | 需能在命令行中使用 `npm` |
| Ollama | 文字情绪理解与音乐 Blueprint 生成 | 服务运行在 `127.0.0.1:11434`，并已准备 `qwen2.5:3b` 模型 |
| ACE-Step | WAV 音乐生成 | 服务运行在 `127.0.0.1:8001`，可加载 `acestep-v15-turbo` |

默认情况下，启动脚本会从 `D:\MuseGarden-ace-step-poc\ACE-Step 1.5` 寻找 ACE-Step。若实际位置不同，应配置环境变量 `MUSEGARDEN_ACESTEP_HOME` 指向 ACE-Step 根目录。

## 3. 一键启动

1. 打开项目根目录 `MuseGarden`；
2. 双击 `启动 MuseGarden.bat`；
3. 启动脚本会依次检查或启动 Ollama、ACE-Step、Garden API 和前端；
4. 等待 ACE-Step 模型初始化完成；
5. 浏览器会自动打开 `http://127.0.0.1:5182/`。

正常情况下，无需分别启动多个服务。运行日志保存在 `development/runtime_logs/`。

## 4. 基本操作

| 操作 | 方法 |
| --- | --- |
| 移动角色 | `W`、`A`、`S`、`D` 或方向键 |
| 创建记忆 | 走到可种植空地，按 `E` |
| 查看花朵记忆 | 靠近已种花朵，按 `E` |
| 删除花朵 | 靠近已种花朵，按 `Delete` |
| 打开或关闭小地图 | 按 `M`；小地图打开时也可按 `Esc` 关闭 |
| 查看地图总览 | 在浏览器打开 `http://127.0.0.1:5182/map-overview` |

## 5. 创建一段音乐记忆

1. 在花园中移动到土地区域的可种植空地；
2. 屏幕出现“`E 创建记忆`”或“`E 种下记忆`”提示时，按 `E`；
3. 在“留下一段记忆”弹窗中输入文字，最多 10000 字；
4. 点击“开始创作”；
5. 等待系统完成情绪理解、音乐生成、花朵生成和种植；
6. 出现“你的记忆已经种下了”后，可试听音乐，点击“完成”返回花园。

生成速度会受到本机性能、Ollama 和 ACE-Step 模型状态影响。生成过程中不要重复点击提交。

## 6. 查看、修改和管理音乐

1. 靠近已种下的花朵，按 `E` 打开“这朵花的记忆”；
2. 在详情中阅读原始文字，点击播放按钮试听音乐；
3. 在“音乐版本”区域选择 V1、V2 等不同版本；
4. 向下滚动可查看“音乐解读”；
5. 点击“修改音乐”，选择一条 AI 建议，或在“修改要求”中自行输入要求；
6. 点击“生成新版音乐”，等待系统生成新的版本；
7. 新版本会保留在版本列表中，旧版本仍可以试听和切换。

版本名称可以点击后修改，名称最多 60 个字符；修改要求最多 500 个字符。

## 7. 删除花朵

走近已种花朵后，页面会显示“`Delete 删除花朵`”。按下 `Delete` 后，系统会移除这朵花和它的种植记录，并提示该土地可以重新种植。

当前规则是：删除花朵不会删除其原始文字记忆、已生成音乐和音乐版本，只会将花朵从花园中移除。

## 8. 常见问题

### 8.1 双击启动脚本后提示找不到 ACE-Step

检查 ACE-Step 是否位于默认目录；若不在默认目录，设置 `MUSEGARDEN_ACESTEP_HOME` 后重新启动。

### 8.2 页面打开但创建音乐失败

检查以下服务是否就绪：

- Ollama：`127.0.0.1:11434`；
- ACE-Step：`127.0.0.1:8001`；
- Garden API：`127.0.0.1:8000`；
- 前端：`127.0.0.1:5182`。

也可查看 `development/runtime_logs/` 中对应服务的日志。

### 8.3 前端页面提示加载失败

通常表示 Garden API 未启动或端口 8000 被其他程序占用。关闭相关服务后重新双击 `启动 MuseGarden.bat`；需要强制重启 Garden API 时，可在 PowerShell 中运行：

```powershell
.\scripts\Start-MuseGarden.ps1 -RestartGardenApi
```

### 8.4 创建完成但花园没有刷新

创建结果弹窗会提示刷新问题。优先使用弹窗中的“重试刷新”；不要立即重复创建，以免产生重复音乐或花朵记录。

## 9. 数据说明与注意事项

- 用户文字、花园记录和音乐文件均保存于本机数据目录；
- 项目属于本地单用户演示，不提供账号、云端同步或多人协作；
- 课程演示请避免输入真实敏感个人信息；
- 退出前可等待当前音乐生成完成，避免中途终止导致记录不完整。
