# MuseGarden 原型页面与交互清单

> 本清单以当前已实现项目为依据，用于确定原型图范围；它不是新增功能清单。

## 一、原型应覆盖的 5 个界面

| 编号 | 页面/状态 | 作用 | 是否需要单独画图 |
| --- | --- | --- | --- |
| P1 | 花园主界面 | 在地图中移动、查看花朵、发现可交互对象 | 是 |
| P2 | 创建记忆弹窗 | 在空地输入文字，开始生成音乐记忆 | 是 |
| P3 | 创建完成状态 | 展示“记忆已种下”、生成结果和试听入口 | 与 P2 画为同一页面的状态变化 |
| P4 | 花朵详情弹窗 | 查看文字、播放音乐、查看解读、修改及管理版本 | 是 |
| P5 | 地图总览页 | 俯瞰花园布局和花朵分布 | 是 |

因此，建议最终准备 **4 张原型图**：P1、P2/P3、P4、P5。

## 二、各页面需要表现的内容

### P1 花园主界面

应画出：

- 像素风花园地图、角色和若干已种植花朵；
- 角色移动提示：`WASD / 方向键移动`；
- 靠近空地时的提示：`E 创建记忆`；
- 靠近花朵时的提示：`E 查看记忆`、`Delete 删除花朵`；
- 地图提示：`M 打开小地图`；
- 可选：右上角小地图，展示玩家位置。

### P2/P3 创建记忆弹窗

P2 输入状态应画出：

- 标题“留下一段记忆”；
- 一段文字输入框、字数提示 `0 / 500`；
- “开始创作”和“取消”按钮；
- 文案“这一刻，你想留下什么？”。

P3 完成状态可作为同一张原型的旁注或第二状态：

- 提示“你的记忆已经种下了”；
- 展示用户输入的文字摘要；
- 音乐试听控件；
- “完成”按钮，返回花园。

### P4 花朵详情弹窗

应画出：

- 花朵像素图、花朵名称和对应文字记忆；
- 音乐版本列表，例如 V1、V2，并标出“当前播放”或“选择试听”；
- 音频播放控件；
- 音乐解读卡片；
- “修改音乐”按钮；
- 修改区域：3 条 AI 建议、修改要求输入框和“生成新版音乐”按钮；
- “返回花园”按钮。

说明：删除花朵不需要另画一个页面，因为它是在 P1 靠近花朵时通过 `Delete` 完成的快捷操作。

### P5 地图总览页

应画出：

- 花园完整俯视地图；
- 已种植花朵的位置标记；
- 简单图例，例如“花朵”“可通行区域”“水域/障碍物”；
- 返回花园的入口。

## 三、核心交互流程

```text
进入花园
  → 移动并找到空地
  → E 打开“创建记忆”
  → 输入文字并开始创作
  → 系统生成音乐与花朵
  → 花朵种入花园
  → 靠近花朵按 E 查看详情
  → 播放 / 查看解读 / 修改音乐 / 管理版本

进入花园
  → 靠近花朵
  → Delete 删除花朵与种植记录
  → 土地恢复为可种植状态
```

## 四、原型阶段的范围说明

- 原型用于说明页面结构和交互，不要求与最终像素素材完全一致；
- 所有原型只表现当前已实现或已确认的功能，不加入账号、社交、云同步等未实现内容；
- 音乐解读在当前版本中会在打开详情或切换版本时自动加载；
- 删除花朵当前没有单独的确认弹窗，原型中只需在主界面操作提示中标出该快捷键。
