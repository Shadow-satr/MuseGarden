# MuseGarden 阶段性里程碑

**状态：核心功能开发阶段暂时收尾；后续仅按需美化与维护。**

## 已实现

- 花园世界、Pixi 场景与 HTML Overlay。
- 四方向玩家、移动动画、地图边界、摄像机与脚底网格交互。
- 逐格地形地图、道路、河流、桥梁、建筑、四块田地和 Mini Map。
- 空地创作、真实 Creation API、种花、1×1 / 3×3 花朵占地与刷新持久化。
- 花朵记忆详情、音频播放、音乐修改和历史版本选择。
- 草地、道路、水面、统一河岸线、桥梁和建筑的基础像素美术。

## 当前验证状态

- 最近一次前端相关回归：TerrainRenderer 5、TerrainMap 9、GardenWorld 4、Player 7、interactions 6、App 12，合计 43 项通过。
- 最近一次 `npm run build` 通过；仅有打包体积提示。
- 正式浏览器已经按各步骤检查地图、摄像机、地形边界、建筑与主要交互。
- 真正的 AI / ACE-Step 音乐生成依赖本机服务和模型准备状态，仍应在需要展示时重新做人工端到端验收。

## 明确搁置

环境装饰不是当前版本功能。此前的灌木、岩石等规划预览仅是开发参考，已因视觉风格不符合预期而搁置；正式游戏没有加载任何此类道具。

后续如继续，只做用户明确提出的 Bug 修复、体验维护或美术方向重设计；不会自动新开功能步骤。
