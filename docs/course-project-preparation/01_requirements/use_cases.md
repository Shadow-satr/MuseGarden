# 主要用例

参与者只有使用者；下列流程从实际代码整理，非真实访谈。

## UC-01 创建
前置：花园和模型服务可用。用户进入空地按 E、输入不超过 10000 字并提交；系统验证位置，生成蓝图和音频，保存记忆、花朵及种植并刷新。无效或空白文字无法正常创建；生成失败应显示错误。

## UC-02 回访与播放
前置：花朵记录和音频存在。用户走近花朵打开详情，查看文字与花朵并播放音频；资源缺失时应报告错误。

## UC-03 修改版本
前置：创作存在且服务可用。用户输入修改要求，服务创建音乐版本，用户可选择、重命名版本；花的位置和初始关联不变。

## UC-04 解读音频
前置：音频资产存在及所需依赖模型可用。用户请求解读；系统读取缓存或计算声学和语义内容，结果对语义结论存在证据限制。

UC-01 已进行一次真实服务层生成，浏览器流程未验证；UC-03/04 的真实模型流程未验证。
