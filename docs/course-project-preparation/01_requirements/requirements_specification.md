# 需求说明

以下是对当前代码的逆向整理，不冒充原始访谈；目标用户和优先级为待验证假设。详细追溯见 requirements_traceability.csv。

|编号|需求|优先级|验收标准|当前状态|
|---|---|---|---|---|
|FR-001|地图与移动|高|用户通过方向键或 WASD 移动，地形和世界边界限制移动|已实现；自动化通过；人工未复测|
|FR-002|输入记忆|高|空地交互打开输入框，去除空白，前端限制 500 字；空白不可提交|已实现；前端测试通过|
|FR-003|创作记忆|高|POST 请求包含 garden_id、text、x、y；成功返回 201 和创作结果；非法输入返回 400|路由测试使用替身；另有一次真实服务层创作通过|
|FR-004|种植冲突|高|非 SOIL 或已占中心拒绝；大花占地不符合时退为小花|自动化通过|
|FR-005|花朵详情与播放|高|显示对应记忆并播放音频资产|前端测试通过；真实音频本次未验收|
|FR-006|修改音乐|高|基于修改文字产生新版蓝图及音频，不重种花|相关测试通过；真实模型未验收|
|FR-007|选择旧版本|中|按 creation_id 和 audio_artifact_id 选择已有音频|路由测试使用替身|
|FR-008|音频分析|中|有效 WAV 生成声学结果；无效路径和不可解码数据报错|自动化通过；部分测试使用虚拟音频|
|FR-009|音乐解读|中|用户主动请求时生成或读取缓存；语义得分不可视为事实证明|模块测试通过；真实模型未复测|
|FR-010|本地恢复|高|重启后从 JSON 恢复保存记录及关联数据|自动化覆盖；整机重启未验收|
|FR-011|删除种植|中|指定 garden_id 与 planting_id 挖除并返回刷新后的花园|代码已实现；此用例未单独执行|
|NFR-001|输入和错误处理|高|空白/格式不合法被拒；依路由返回 400、404 或 503|部分已测；异常场景需扩大|
|NFR-002|可恢复与一致性|高|单文件保存尝试临时文件替换；跨文件不保证事务|部分实现；中途失败恢复待验证|
|NFR-003|性能|中|记录环境、输入和响应时间；目标阈值尚未确定|种植函数微基准已测；整机响应未测|
|NFR-004|隐私与权限|中|本地数据不纳入版本库；服务默认仅监听回环地址|代码与配置已查；不等于安全测试|
|NFR-005|可用性|中|用户可理解提示、完成主流程；无量化达标标准|待真实体验者验证|

需求覆盖正常输入、异常、数据限制、持久化与性能；安全、性能和真实用户体验尚无充分证据。
