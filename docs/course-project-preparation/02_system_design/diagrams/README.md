# 图表说明

architecture.svg 是架构示意；creation、planting、use_cases、data、version_state 和 deployment 的 SVG 是按实际代码制作的可查看流程概览。对应 .mmd 为可编辑 Mermaid 草图（deployment.mmd 除外），SVG 是独立整理的概述，不承诺由 Mermaid 直接导出。数据图是引用关系，不表示数据库外键；若需严格 UML，时序、用例和状态草图仍应按学校规范调整。

class_model.svg 与 class_model.mmd 展示部分 Pydantic 模型字段及引用，完整字段以 CSV 和源码为准。
