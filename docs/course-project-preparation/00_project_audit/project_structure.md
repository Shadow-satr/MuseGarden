# 项目结构

| 目录 | 职责 |
|---|---|
| frontend/src | React 界面与 Pixi 世界 |
| backend/app | HTTP 路由、请求模型及花园交互服务 |
| application | 创作编排和空间种植规则 |
| ai_engine | 情绪、蓝图、记忆及 LLM 客户端 |
| music_engine | ACE-Step 调用、音频、版本 |
| music_companion | 声学分析、语义解读、建议 |
| flower_engine | 花朵、花园领域模型与存储 |
| database | 本地数据目录；不是已建立的关系数据库 |
| test | Python 自动化测试 |
| docs/architecture | 既有进展、约束和设计记录 |
依据：仓库当前代码和已有开发记录；未经本次运行验证的结论标明为代码审计或历史记录。个人项目，开发者为同一人。
